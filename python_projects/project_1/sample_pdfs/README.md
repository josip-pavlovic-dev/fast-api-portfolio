# Testni PDF fajlovi

Ovi sintetički dokumenti služe za lokalno vežbanje. Ne sadrže stvarne lične,
finansijske niti ugovorne podatke.

- `01_racun.pdf`: 1 stranica.
- `02_priznanice.pdf`: 2 stranice.
- `03_ugovor.pdf`: 4 stranice.

Svaka stranica ima oznaku dokumenta i broj stranice. Ako sva tri fajla spojiš
ovim redosledom, očekivani rezultat ima 7 stranica.

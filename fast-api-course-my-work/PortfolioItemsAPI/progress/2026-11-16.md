## Šta je naučeno / razjašnjeno

- Projekat je organizovan unapred po odgovornostima (`api`, `db`, `models`, `schemas`), ali prazna struktura još ne predstavlja funkcionalnu aplikaciju.
- Planirani SQLAlchemy modeli i Pydantic šeme nisu isto: ORM modeli će opisivati bazne tabele, a Pydantic modeli API ulaz i izlaz.
- Planirani `items` red povezuje se sa korisnikom preko `owner_id` i sa kategorijom preko `category_id`; tačan schema dizajn treba tek obraditi.
